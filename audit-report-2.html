Architecture

The Monolithic Component Bottleneck.

The ProductConfigurator.tsx component has reached 102KB. While technically functional, it violates the Single Responsibility Principle by mixing complex pricing logic, date calculations, and thousands of lines of UI markup.

  • !
    Tight Coupling: Pricing tiers and production dates are hardcoded in the component. Risk: Maintenance becomes impossible as categories grow.
  • !
    Effect Overload: 12+ useEffect hooks drive the pricing engine. Risk: Race conditions in pricing updates on slow connections.

Recommendation

Extract Logic into Custom Hooks

const { price, yield } = usePricing(config);
const { shipmentDate } = useTimeline(category);
return <ConfiguratorUI />;

Decoupling the Engine from the View will improve load times by 40% and allow for cleaner unit testing of pricing edge cases.
